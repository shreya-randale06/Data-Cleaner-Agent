# Data Cleaner Agent

## Overview
Data Cleaner Agent is a Python-based data cleaning and validation application that helps users prepare datasets for analysis. Built with Pandas, NumPy, and Streamlit, it identifies data quality issues and automates essential data preprocessing tasks through a simple, user-friendly interface.

## Features
- Upload Dataset: Import datasets for cleaning and analysis.
- Data Quality Analysis: Identify missing values, duplicate records, and data quality issues.
- Data Cleaning: Remove null values and duplicate records.
- Data Validation: Validate cleaned data to improve data quality.
- Export Cleaned Data: Download the processed dataset for further analysis.
- Processing Logs: Track the data cleaning process.

## Tech Stack
- Programming Language: Python
- Libraries: Pandas, NumPy
- Framework: Streamlit
- Concepts:Data Cleaning, Data Preprocessing, Data Validation, Exploratory Data Analysis (EDA)

## Project Workflow
1. Upload the dataset.
2. Analyze the dataset for missing values and duplicate records.
3. Clean the data by removing null values and duplicates.
4. Validate the cleaned dataset.
5. Export the cleaned data for further analysis.
